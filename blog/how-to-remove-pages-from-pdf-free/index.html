How To Remove Pages From A PDF For Free: 4 Easy Ways

By PDF Ad Cleaner · Updated October 19, 2026 · 3 min read

Deleting unwanted pages is the simplest way to clean a PDF. Here are four free ways to remove pages from a PDF, from a one-minute browser method to a command line option for large batches.

  2. Method 2: A PDF Reader With Page Tools
  3. Method 3: Print To PDF
  4. Method 4: Command Line For Batches

Method 1: A Browser Page Cleaner

The fastest way for most people. Open the free PDF cleaner, choose a PDF, click the pages to remove, press Clean PDF and download. Your file stays in the browser. You can also type a range like 1-2, 9 to select several pages at once.

Method 2: A PDF Reader With Page Tools

Many desktop PDF programs let you delete pages from a thumbnail panel. Open the PDF, show thumbnails, select the pages, choose delete and save as a new file. Features and prices vary between programs, and some basic readers do not allow editing. For a visual walk-through of page deletion in a web editor, see the video on our homepage.

Method 3: Print To PDF

Open the PDF in any viewer and choose Print. Select “Save as PDF”, enter only the page ranges you want to keep, such as 3-12, and save. It is free and built into most systems. The trade-off is that printing can change fonts, links and bookmarks, and the file may be re-rendered, so check quality.

Method 4: Command Line For Batches

If you clean many documents, a library such as Python’s pypdf can remove pages in a script. This is the most flexible method but needs some technical comfort. Always test on copies first.

Which Method Should You Use?

  • One file, quickly: browser page cleaner.
  • You already own a PDF program: its page tools.
  • No tools at all: print to PDF.
  • Hundreds of files: scripting.

Safety Checks After Removing Pages

  1. Open the new file and check the page count.
  2. Scroll through quickly for missing content.
  3. Test text selection and links.
  4. Keep the original until you are sure.

What Page Removal Cannot Do

Dedicated page removal keeps remaining pages as they were. Print to PDF may re-render them.

Mark them by clicking thumbnails or use a range such as 1-3, 8.
